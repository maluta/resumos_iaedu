# Resumos IA EDU

Este repositório hospeda os arquivos estáticos da página pública com resumos sobre IA e educação.

- Propósito: centralizar e divulgar resumos curtos e organizados sobre IA e educação para consulta rápida e compartilhamento.
- Página publicada: https://maluta.github.io/resumos_iaedu/
- Código que gera a página: https://github.com/maluta/whatsapp_cli_tools

Observação: este repositório contém apenas o site gerado. O processo de geração/atualização está no repositório indicado acima.
